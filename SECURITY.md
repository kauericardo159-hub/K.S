# 🛡️ Política de Segurança (Security Policy)

## Versões Suportadas

Como este repositório passa por constantes testes e reestruturações completas do zero, **não utilizamos uma branch `main` estável de forma vitalícia**. O suporte de segurança é aplicado apenas às branches de desenvolvimento ativo.

| Versão / Branch | Suportado | Notas |
| :--- | :---: | :--- |
| Active (Branch de Teste Atual) |  ✅  | A branch que estiver ativa no momento recebe correções imediatas. |
| Branches Antigas / Arquivadas |  ❌  | Versões antigas ou descartadas não recebem manutenção. |

## Como reportar uma vulnerabilidade ou bug crítico

Se você encontrar alguma falha de segurança, brecha nos scripts (`painel.js`, `manutencao.js`, etc.) ou vazamento de dados estruturais nas minhas branches de teste, **por favor, não abra uma "Issue" pública**. 

Para reportar de forma segura:
1. Entre em contato diretamente comigo pelas minhas redes sociais privadas (especificadas no `creditos.js` ou no perfil do GitHub).
2. Explique brevemente o problema e como reproduzi-lo.
3. Eu irei analisar e aplicar a correção diretamente na branch de testes atual ou iniciarei uma nova branch do zero com a correção.

Obrigado por ajudar a manter o projeto seguro!
