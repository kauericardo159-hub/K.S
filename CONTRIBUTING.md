# 🤝 Guia de Contribuição (Contributing)

Olá! Se você chegou até aqui, provavelmente viu alguma de minhas branches de teste ou o desenvolvimento de uma nova versão do zero.

## Este projeto é Restrito 🔒

Antes de pensar em enviar qualquer alteração, lembre-se: **Este projeto possui uma Licença Proprietária**. Isso significa que:
- O desenvolvimento é feito de forma pessoal e independente.
- Não aceitamos *Pull Requests* (PRs) de código sem aviso prévio ou autorização expressa.

## Como posso ajudar ou interagir?

Se você gostou da lógica, do painel dinâmico com favicons ou da tela de manutenção e quer trocar uma ideia:
1. **Dê uma olhada no código:** Sinta-se livre para clonar para a sua máquina local para estudar o funcionamento.
2. **Reporte Bugs:** Se algo quebrar em alguma branch ativa, você pode abrir uma *Issue* descrevendo o erro (exceto falhas de segurança, que devem seguir o `SECURITY.md`).
3. **Se quiser sugerir algo:** Me procure no privado. Se a ideia for incrível, eu mesmo posso aplicar na próxima branch que eu criar do zero!

## Lembrou dos Créditos?
Se for usar a estrutura deste repositório como base ou inspiração para o seu próprio site, consulte o arquivo [LICENSE](./LICENSE) para saber como aplicar a atribuição obrigatória ao autor (**KaueTheProtogen**).
